# 🪐 Planet Merge Game (Watermelon Game Style)

Unity로 제작된 '수박 게임(Suika Game)' 스타일의 행성 병합 퍼즐 게임입니다. 같은 종류의 행성을 충돌시켜 더 큰 행성으로 진화시키고, 가장 높은 점수를 획득하는 것이 목표입니다.

## 🎮 게임 방법 (How to Play)

1. **행성 떨어뜨리기**: 마우스를 움직여 행성을 떨어뜨릴 위치를 조준합니다.
2. **소환**: 마우스 왼쪽 버튼을 클릭하면 행성이 떨어집니다. (0.3초 쿨타임)
3. **병합 (Merge)**: 같은 종류의 행성끼리 부딪히면 다음 단계의 더 큰 행성으로 합쳐집니다.
4. **점수 획득**: 행성이 병합될 때마다 점수를 얻습니다.
5. **게임 오버**: 행성들이 쌓여 게임 화면 위쪽의 데드라인을 넘어가면 게임이 종료됩니다.

## 🕹 조작법 (Controls)

| 동작 | 입력장치 | 설명 |
| :--- | :---: | :--- |
| **조준** | 마우스 이동 | 행성을 떨어뜨릴 X축 위치를 조정합니다. |
| **떨어뜨리기** | 마우스 왼쪽 클릭 | 조준한 위치에 행성을 소환합니다. |
| **재시작** | UI 버튼 | 게임 오버 시 다시 시작할 수 있습니다. |

## 🌟 주요 기능 (Features)

- **물리 엔진 기반**: Unity의 2D 물리 엔진(Rigidbody2D)을 사용하여 자연스러운 행성의 움직임과 충돌을 구현했습니다.
- **점수 시스템**: 행성을 합칠 때마다 `(현재 단계 + 1) * 10` 점을 획득합니다.
- **미리보기**: 다음에 소환될 행성을 미리 보여주어 전략적인 플레이가 가능합니다.
- **최적화된 병합 로직**: 동시에 여러 행성이 충돌해도 안정적으로 하나로 병합되도록 쿨타임과 병합 상태 관리가 적용되어 있습니다.

## 🛠 기술 스택 (Tech Stack)

- **Engine**: Unity 6 (or latest version used)
- **Language**: C#
- **Component**: 
  - `Input System`: 최신 Unity Input System 패키지 사용
  - `TMPro`: 깔끔한 UI 텍스트 렌더링
  - `Physics 2D`: 충돌 및 중력 시뮬레이션
